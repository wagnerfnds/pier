How Pier works

Your agents (Claude Code, Codex) keep running on your own development machine, which Pier calls a box: a Linux server or your Mac. It runs pierd, a small open-source server, and the Pier app on your iPhone, iPad and Mac talks to it directly. There is no cloud and no Pier account: the app pairs with each box once (a QR code or a pier:// link), then uses mutual TLS with pinned keys. Away from the box's network, the app goes through the Pier tunnel, which only carries the end-to-end encryption.

What you need

BoxA Linux server (Ubuntu 20.04+ or Debian 10+, x86-64 or arm64, with systemd) or a Mac (macOS 13+), 4 GB of RAM or more.
On the boxgit, tmux, curl. Optional: gh (pull requests, your GitHub repositories) and Docker (isolated environments).
AgentsClaude Code with a Pro, Max, Team or Enterprise plan, and/or Codex with a ChatGPT account or an API key.
DevicesAn iPhone or iPad on iOS 17 or later, and/or a Mac.

No box yet? Open the app and tap Explore with sample data.

1. Prepare the server

Skip this on a Mac. On a fresh Ubuntu or Debian server, over SSH, as the user your agents will run as (not root):

sudo apt update && sudo apt install -y git tmux curl gh
gh auth login                       # GitHub.com › HTTPS › sign in with a browser
git config --global user.name  "Your Name"
git config --global user.email "you@example.com"

For isolated environments, install Docker from docs.docker.com/engine/install, then sudo usermod -aG docker $USER and log in again. A server with a public address needs no VPN (pierd only answers paired devices; open port 7444 if a firewall is on). A server at home or behind NAT needs nothing either: the app reaches it through the tunnel.

2. Install the agents

curl -fsSL https://claude.ai/install.sh | bash     # Claude Code
npm install -g @openai/codex                        # Codex

Signing in can wait: the app does it per account (step 6).

3. Install pierd

curl -fsSL https://docktopier.com/install.sh | sh
# or: npm install -g pierd && pierd setup
# or: brew install wagnerfnds/tap/pierd && pierd setup

pierd setup runs pierd as a user service on port 7444, installs the agents' hooks, adds the git repositories it finds (~/code, ~/Projects, …), connects the box to the tunnel and prints a QR code and a pier:// link (single use, 10 minutes). On Linux, run sudo loginctl enable-linger $USER once so pierd keeps running after you log out. Then pierd doctor should say “All good.”, and pierd pair makes a new link any time.

4. Connect the iPhone and iPad

  1. Install Pier from the App Store.
  2. Tap Scan QR code and point it at the code in the terminal (after the first box: Settings › Add box). Or open the pier:// link on the device.
  3. The box shows up with its projects and sessions; the app switches between the direct connection and the tunnel by itself.

5. Connect the Mac

  • Install Pier from the App Store, or download the .dmg (macOS 14 or later): open it and drag Pier to Applications.
  • The box is a server: in Pier on the Mac, Paste link and paste a pier:// link.
  • The box is the Mac itself: run the installer in Terminal; pierd setup hands the link to Pier, which pairs by itself.
  • Take it to iPhone (Settings on the Mac) shows a QR code that brings the phone into the same boxes.

6. Claude and Codex accounts

Several subscriptions on one box (personal and work, two Max plans…): each account is a folder of the agent's own (CLAUDE_CONFIG_DIR, CODEX_HOME), with its own login, settings and history, as Claude Code's documentation recommends for several accounts.

  1. Settings › Projects › Claude and Codex accounts: the agents' own accounts are listed already.
  2. Sign in, or Add account and name it: a terminal of the box opens in the app for the agent's sign-in.
  3. Each project picks its account (the project's screen, Agents' account, or a worktree's Details); Make default sets it for everything else.
  4. The Home's Usage limits card shows each account's 5-hour and weekly use; tap Turn on reading the limits once for Claude. A tap on an account makes it the default.

7. Projects folder and spaces

Settings › Projects › Projects folder and spaces: every project lives under the folder you pick (such as ~/code): clones go there, nothing outside it is added or deleted. Spaces are folders in it that keep groups of projects apart (one per client, say); deleting a space deletes its projects with it, after the same checks as removing one, and never moves them out.

8. The box's variables and skills

Settings › Projects › Variables and skills: variables every project gets (agents, terminals, services), each with a note on what it is for. Secret-looking values are hidden until revealed; a project's own env wins. Turn on the Pier box skill (the variables by name and note, never values; the worktree's ports; the project's environment) and Pier preview (run the dev server on the worktree's port) so Claude Code and Codex know them.

9. Bring in projects

  • Projects › + › GitHub repositories: the account gh is signed in to on the box; a tap downloads one and, with “Set up the environment”, installs its dependencies and starts its dev server.
  • Clone from link: owner/repo, a GitHub page or a clone URL. Setup starts off here, since it runs the repository's own config: turn it on for repositories you trust.
  • Remove from disk: shows the space it frees and what would be lost (uncommitted files, unpushed commits, stashes) before deleting anything.

10. Isolated environments

A project's Environment picks its language version (PHP, Node.js, Python, Ruby, Go, an image, or its own Dockerfile) and its databases (MySQL, MariaDB, PostgreSQL, Redis, MongoDB), all in Docker on the box and none of it in the project. After Apply, php, composer, node… run in the container for everything in the project, agents included, and the worktrees get DB_HOST, DB_PORT, DATABASE_URL, REDIS_URL (user root, password pier, database app).

11. Notifications

Nothing to set up: Pier on the Mac tells your iPhone and iPad what needs you through your own iCloud while it is open (Settings › Open Pier when the Mac starts). Buttons in the notification answer the agent directly.

Day to day

Start a task+ on the Home: pick the project and the agent, type or dictate; it gets a worktree of its own.
What needs meInbox: permissions and questions, answered with a tap.
Everything at onceBoard: working, needs you, done.
ReviewA session's Review: each file's diff, commit, push, pull request.
See it runningA worktree's Details: dev servers with their links, services, ports.
Clean upCleanup (Projects › ✦): unused worktrees, services, every project's main.

Public links

A worktree's Details › Create public link puts its dev server at https://p-<name>.docktopier.com for 24 hours (7 days at most), for anyone with the link. It goes when it expires, when you take it down, or with its worktree.

Never publish a server with a debug console on (Rails' web-console, Django's debug toolbar): anyone with the link reaches it.

Useful commands

pierd doctorWhat works and how to fix the rest.
pierd pairA new pairing link and QR code.
pierd clients / pierd revoke NAMEPaired devices / remove one.
pierd relayThe tunnel's state; off / default.
pierd location add NAME DIRA repository setup did not find.
UpdateRun the install command again (or npm install -g pierd@latest, brew upgrade pierd); running agents keep running.

Common problems

The app can't reach the box

pierd doctor; on the same network the device must reach the link's address (pierd setup --address HOST); away from it, pierd relay should say connected. On a Mac with the firewall on, allow incoming connections for pierd.

An agent stops at its login

That project's account is signed out: Settings › Projects › Accounts › Sign in.

No limits on the Home

Turn on reading the limits for Claude and wait for an agent's next reply. Limits exist for claude.ai plans only, not API keys.

An isolated environment does not apply

Check docker version on the box and that your user is in the docker group; the Environment screen shows the error and the log's end.

Como o Pier funciona

Os seus agentes (Claude Code, Codex) continuam rodando na sua máquina de desenvolvimento, que o Pier chama de box: um servidor Linux ou o seu Mac. Nela roda o pierd, um servidor pequeno e de código aberto, e o app no iPhone, no iPad e no Mac conversa direto com ele. Não existe nuvem nem conta do Pier: o app pareia com cada box uma vez (um QR code ou um link pier://) e daí usa TLS mútuo com chaves fixadas. Fora da rede da box, o app passa pelo túnel do Pier, que só carrega a criptografia de ponta a ponta.

O que você precisa

BoxUm servidor Linux (Ubuntu 20.04+ ou Debian 10+, x86-64 ou arm64, com systemd) ou um Mac (macOS 13+), com 4 GB de RAM ou mais.
Na boxgit, tmux, curl. Opcionais: gh (pull requests, seus repositórios do GitHub) e Docker (ambientes isolados).
AgentesClaude Code com plano Pro, Max, Team ou Enterprise, e/ou Codex com conta ChatGPT ou chave de API.
AparelhosiPhone ou iPad com iOS 17 ou mais novo, e/ou um Mac.

Ainda sem box? Abra o app e toque em Explorar com dados de exemplo.

1. Preparar o servidor

Pule no Mac. Num servidor Ubuntu ou Debian novo, por SSH, com o usuário que vai rodar os agentes (não use root):

sudo apt update && sudo apt install -y git tmux curl gh
gh auth login                       # GitHub.com › HTTPS › login pelo navegador
git config --global user.name  "Seu Nome"
git config --global user.email "voce@exemplo.com"

Para ambientes isolados, instale o Docker pelo guia oficial (docs.docker.com/engine/install) e depois sudo usermod -aG docker $USER, entrando de novo na sessão. Um servidor com IP público não precisa de VPN (o pierd só atende aparelhos pareados; libere a porta 7444 se houver firewall). Um servidor em casa ou atrás de NAT também não precisa de nada: o app chega pelo túnel.

2. Instalar os agentes

curl -fsSL https://claude.ai/install.sh | bash     # Claude Code
npm install -g @openai/codex                        # Codex

O login pode esperar: o app faz isso conta por conta (passo 6).

3. Instalar o pierd

curl -fsSL https://docktopier.com/install.sh | sh
# ou: npm install -g pierd && pierd setup
# ou: brew install wagnerfnds/tap/pierd && pierd setup

O pierd setup roda o pierd como serviço do usuário na porta 7444, instala os hooks dos agentes, adiciona os repositórios git que encontrar (~/code, ~/Projects, …), conecta a box ao túnel e mostra um QR code e um link pier:// (uso único, 10 minutos). No Linux, rode uma vez sudo loginctl enable-linger $USER para o pierd continuar rodando depois do logout. Depois, pierd doctor deve dizer “All good.”, e pierd pair gera um link novo quando precisar.

4. Conectar o iPhone e o iPad

  1. Instale o Pier pela App Store.
  2. Toque em Escanear QR code e aponte para o código do terminal (depois da primeira box: Ajustes › Adicionar box). Ou abra o link pier:// no aparelho.
  3. A box aparece com os projetos e as sessões; o app alterna sozinho entre a conexão direta e o túnel.

5. Conectar o Mac

  • Instale o Pier pela App Store ou baixe o .dmg (macOS 14 ou mais novo): abra e arraste o Pier para Aplicativos.
  • A box é um servidor: no Pier do Mac, Colar link e cole um link pier://.
  • A box é o próprio Mac: rode o instalador no Terminal; o pierd setup entrega o link ao Pier, que pareia sozinho.
  • Levar para o iPhone (Ajustes, no Mac) mostra um QR code que traz o celular para as mesmas boxes.

6. Contas do Claude e do Codex

Várias assinaturas na mesma box (pessoal e trabalho, dois planos Max…): cada conta é uma pasta própria do agente (CLAUDE_CONFIG_DIR, CODEX_HOME), com login, configurações e histórico separados, como a documentação do Claude Code recomenda para várias contas.

  1. Ajustes › Projetos › Contas do Claude e do Codex: as contas próprias dos agentes já aparecem.
  2. Entrar, ou Adicionar conta e dê um nome: abre um terminal da box no app para o login do agente.
  3. Cada projeto escolhe a sua conta (tela do projeto, Conta dos agentes, ou Detalhes de uma worktree); Tornar padrão vale para o resto.
  4. O card Limites de uso no Início mostra o uso de 5 horas e semanal de cada conta; toque uma vez em Ativar a leitura dos limites para o Claude. Um toque numa conta a torna a padrão.

7. Pasta dos projetos e espaços

Ajustes › Projetos › Pasta dos projetos e espaços: todos os projetos ficam na pasta que você escolher (por exemplo ~/code): os clones vão para lá, e nada fora dela é adicionado ou apagado. Espaços são pastas dentro dela que separam grupos de projetos (um por cliente, por exemplo); apagar um espaço apaga os projetos dele junto, com as mesmas checagens de remover um projeto, e nunca os move para fora.

8. Variáveis da box e skills

Ajustes › Projetos › Variáveis e skills: variáveis que todo projeto recebe (agentes, terminais, serviços), cada uma com uma nota do que é. Valores com cara de segredo ficam escondidos até você revelar, e o env do projeto tem prioridade. Ligue a skill Pier box (as variáveis por nome e nota, nunca o valor; as portas da worktree; o ambiente do projeto) e a Pier preview (subir o servidor de desenvolvimento na porta da worktree) para o Claude Code e o Codex saberem disso.

9. Trazer os projetos

  • Projetos › + › Repositórios do GitHub: a conta do gh na box; um toque baixa e, com “Configurar o ambiente”, instala as dependências e sobe o servidor de desenvolvimento.
  • Clonar por link: dono/repo, a página no GitHub ou a URL de clone. Aqui o setup começa desligado, porque roda a configuração do próprio repositório: ligue para repositórios em que você confia.
  • Remover do disco: mostra o espaço que libera e o que se perderia (arquivos não commitados, commits sem push, stashes) antes de apagar.

10. Ambiente isolado

O Ambiente de um projeto escolhe a versão da linguagem (PHP, Node.js, Python, Ruby, Go, uma imagem ou o Dockerfile do projeto) e os bancos (MySQL, MariaDB, PostgreSQL, Redis, MongoDB), tudo em Docker na box e nada dentro do projeto. Depois de Aplicar, php, composer, node… rodam no container para tudo do projeto, inclusive os agentes, e as worktrees recebem DB_HOST, DB_PORT, DATABASE_URL, REDIS_URL (usuário root, senha pier, banco app).

11. Notificações

Nada para configurar: o Pier no Mac avisa o iPhone e o iPad pelo seu iCloud, enquanto está aberto (Ajustes › Abrir o Pier quando o Mac ligar). Os botões da notificação respondem direto ao agente.

O dia a dia

Começar uma tarefa+ no Início: projeto, agente, e o pedido digitado ou ditado; ganha uma worktree própria.
O que precisa de mimInbox: permissões e perguntas, respondidas com um toque.
Tudo de uma vezQuadro: trabalhando, precisa de você, terminou.
RevisarRevisar numa sessão: o diff de cada arquivo, commit, push, pull request.
Ver rodandoDetalhes da worktree: servidores com os links, serviços, portas.
LimparFaxina (Projetos › ✦): worktrees sem uso, serviços, a main de cada projeto.

Links públicos

Em Detalhes da worktree › Criar link público, o servidor de desenvolvimento fica em https://p-<nome>.docktopier.com por 24 horas (no máximo 7 dias), para qualquer pessoa com o link. Ele sai do ar quando expira, quando você o remove, ou com a worktree.

Nunca publique um servidor com console de depuração ligado (web-console do Rails, debug toolbar do Django): quem tem o link chega a ele.

Problemas comuns

O app não alcança a box

pierd doctor; na mesma rede, o aparelho precisa alcançar o endereço do link (pierd setup --address HOST); fora dela, pierd relay deve dizer connected. No Mac com firewall, permita conexões de entrada para o pierd.

Um agente para pedindo login

A conta daquele projeto está sem login: Ajustes › Projetos › Contas › Entrar.

Sem limites no Início

Ative a leitura dos limites para o Claude e espere a próxima resposta de um agente. Os limites existem só nos planos claude.ai, não com chave de API.

O ambiente isolado não aplica

Confira docker version na box e se o seu usuário está no grupo docker; a tela do Ambiente mostra o erro e o fim do log.
