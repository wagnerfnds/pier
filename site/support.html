What you need

  • A box: a Linux machine (x86-64 or arm64) with git, tmux, systemd and the agents you use (Claude Code, Codex), signed in. gh for the pull request features.
  • An iPhone or iPad with iOS 17 or later, or a Mac.

No box yet? Open the app and tap Explore with sample data: a demo with made-up projects and agents.

1. Install pierd on the box

pierd is built from the repository (Go 1.25 or later, standard library only):

git clone https://github.com/wagnerfnds/pier
cd pier/Server/pierd
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -o pierd ./cmd/pierd
scp pierd you@devbox:~/.local/bin/

Then, on the box, as the user your agents run as:

pierd install --listen <box-ip>:7444   # a user service, and the agents' hooks
sudo loginctl enable-linger $USER        # keeps it running after you log out
pierd location add web ~/code/web        # the repositories the app should see
pierd doctor                             # checks the setup

2. Pair the app

pierd pair

It prints a single-use pier:// link and its QR code. On the iPhone or iPad, scan it from the app; on the Mac, paste the link. Another device can be invited from Settings → Take it to iPhone.

Common problems

The app can't reach the box

The device must reach the address given to --listen: the same network, or a VPN such as Tailscale. On the box, systemctl --user status pierd tells whether it is running and pierd doctor what to fix.

The pairing link doesn't work

Links work once and for 10 minutes. Run pierd pair again for a new one.

Files and the editor say the box needs a newer pierd

Build pierd again from the repository, replace the binary and restart it: systemctl --user restart pierd. Running agents keep running.

Notifications

Pier shows what needs you while it is open. Push notifications to a locked phone are sent by your box through Apple's service, with an APNs key for the app: today that works when you build the app yourself (docs/PUSH.md).

Remove a device

In the app, Settings → swipe the box → Unpair. On the box, pierd clients lists the paired devices and pierd revoke <name> removes one.

O que você precisa

  • Uma box: uma máquina Linux (x86-64 ou arm64) com git, tmux, systemd e os agentes que você usa (Claude Code, Codex), já logados. O gh para os recursos de pull request.

Ainda sem box? Abra o app e toque em Explorar com dados de exemplo: uma demonstração com projetos e agentes inventados.

1. Instale o pierd na box

O pierd é compilado a partir do repositório (Go 1.25 ou mais novo, só a biblioteca padrão):

git clone https://github.com/wagnerfnds/pier
cd pier/Server/pierd
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -o pierd ./cmd/pierd
scp pierd voce@devbox:~/.local/bin/

Depois, na box, com o usuário que roda os seus agentes:

pierd install --listen <ip-da-box>:7444   # um serviço de usuário e os hooks dos agentes
sudo loginctl enable-linger $USER          # continua rodando depois do logout
pierd location add web ~/code/web          # os repositórios que o app deve ver
pierd doctor                               # confere a instalação

2. Pareie o app

pierd pair

Ele mostra um link pier:// de uso único e o QR code dele. No iPhone ou no iPad, escaneie pelo app; no Mac, cole o link. Outro aparelho pode ser convidado em Ajustes → Levar para o iPhone.

Problemas comuns

O app não alcança a box

O aparelho precisa chegar ao endereço passado em --listen: a mesma rede ou uma VPN como o Tailscale. Na box, systemctl --user status pierd diz se ele está rodando e pierd doctor o que corrigir.

O link de pareamento não funciona

Os links valem uma vez e por 10 minutos. Rode pierd pair de novo para gerar outro.

Arquivos e editor dizem que a box precisa de um pierd mais novo

Compile o pierd de novo a partir do repositório, troque o binário e reinicie: systemctl --user restart pierd. Os agentes que estão rodando continuam rodando.

Notificações

O Pier mostra o que precisa de você enquanto está aberto. As notificações push com o celular bloqueado são enviadas pela sua box através do serviço da Apple, com uma chave APNs do app: hoje isso funciona quando você compila o app (docs/PUSH.md).

Remover um aparelho

No app, Ajustes → deslize a box → Desparear. Na box, pierd clients lista os aparelhos pareados e pierd revoke <nome> remove um.
