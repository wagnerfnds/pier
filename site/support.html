What you need

  • Where your agents run: a Linux server (x86-64 or arm64, with systemd) or a Mac, with git, tmux and the agents you use (Claude Code, Codex), signed in. gh for the pull request features.
  • An iPhone or iPad with iOS 17 or later, or a Mac.

No box yet? Open the app and tap Explore with sample data: a demo with made-up projects and agents.

1. Install pierd

On the server (over SSH) or in Terminal on your Mac, as the user your agents run as:

curl -fsSL https://docktopier.com/install.sh | sh

Or with npm: npm install -g pierd && pierd setup. Or with Homebrew: brew install wagnerfnds/tap/pierd && pierd setup.

It installs Claude Code, Codex and the GitHub CLI where they are missing (no sudo), pierd as a service with the agents' hooks, adds the git repositories it finds (~/code, ~/Projects, …) and prints a pairing link with its QR code. On a Linux server it also turns on lingering so pierd keeps running after you log out; if the system does not let your user do that, whoever runs the server runs sudo loginctl enable-linger $USER once.

2. Pair the app

  • On a server: scan the QR code with Pier on your iPhone or iPad, or paste the pier:// link in Pier on your Mac.
  • On your Mac: the link opens Pier, which pairs with your Mac by itself. Then Take it to iPhone (at the end of the setup, or in Settings) shows a code for your phone.

Links work once, for 10 minutes; pierd pair prints a new one. A repository it did not find: pierd location add web ~/code/web.

Common problems

The app can't reach the box

The device must reach the address in the pairing link: a server's public address, or the same network as a Mac or a server at home. pierd doctor says what to fix; pierd setup --address HOST makes a link with another address. On a Mac with the firewall on (System Settings → Network → Firewall), allow incoming connections for pierd.

Away from home: nothing to set up. pierd keeps a connection to the Pier tunnel, and the app goes through it when it cannot reach the box directly; the tunnel only carries the end-to-end encryption. pierd relay says whether the box is connected to it; pierd relay off turns it off, and pierd relay use HOST points the box at a relay of your own instead.

The pairing link doesn't work

Links work once and for 10 minutes. Run pierd pair again for a new one.

Files and the editor say the box needs a newer pierd

Run the install command again (or npm update -g pierd, brew upgrade pierd, then pierd install): pierd restarts with the new version. Running agents keep running.

Notifications

Nothing to set up: Pier on your Mac tells your iPhone and iPad what needs you through your own iCloud, while it is open (Settings → Open Pier when the Mac starts). Without a Mac, Pier shows what needs you while it is open; a box can also push by itself with your own APNs key when you build the app yourself (docs/PUSH.md).

Remove a device

In the app, Settings → swipe the box → Unpair. On the box, pierd clients lists the paired devices and pierd revoke <name> removes one.

O que você precisa

  • Onde seus agentes rodam: um servidor Linux (x86-64 ou arm64, com systemd) ou um Mac, com git, tmux e os agentes que você usa (Claude Code, Codex), já logados. O gh para os recursos de pull request.
  • Um iPhone ou iPad com iOS 17 ou mais novo, ou um Mac.

Ainda sem box? Abra o app e toque em Explorar com dados de exemplo: uma demonstração com projetos e agentes inventados.

1. Instale o pierd

No servidor (por SSH) ou no Terminal do seu Mac, com o usuário que roda os seus agentes:

curl -fsSL https://docktopier.com/install.sh | sh

Ou pelo npm: npm install -g pierd && pierd setup. Ou pelo Homebrew: brew install wagnerfnds/tap/pierd && pierd setup.

Ele instala o Claude Code, o Codex e o GitHub CLI quando faltam (sem sudo), o pierd como serviço com os hooks dos agentes, adiciona os repositórios git que encontrar (~/code, ~/Projects, …) e mostra um link de pareamento com o QR code. Num servidor Linux ele também liga o lingering para o pierd continuar rodando depois do logout; se o sistema não deixar o seu usuário fazer isso, quem administra o servidor roda uma vez sudo loginctl enable-linger $USER.

2. Pareie o app

  • Num servidor: escaneie o QR code com o Pier no iPhone ou no iPad, ou cole o link pier:// no Pier do Mac.
  • No seu Mac: o link abre o Pier, que pareia com o Mac sozinho. Depois, Levar para o iPhone (no fim da configuração ou nos Ajustes) mostra um código para o celular.

Os links valem uma vez, por 10 minutos; pierd pair gera outro. Um repositório que ele não achou: pierd location add web ~/code/web.

Problemas comuns

O app não alcança a box

O aparelho precisa chegar ao endereço do link de pareamento: o endereço público de um servidor, ou a mesma rede de um Mac ou de um servidor em casa. pierd doctor diz o que corrigir; pierd setup --address HOST gera um link com outro endereço. Num Mac com o firewall ligado (Ajustes do Sistema → Rede → Firewall), permita conexões de entrada para o pierd.

Fora de casa: nada para configurar. O pierd mantém uma conexão com o túnel do Pier, e o app passa por ele quando não alcança a box diretamente; o túnel só carrega a criptografia de ponta a ponta. pierd relay diz se a box está conectada a ele; pierd relay off desliga, e pierd relay use HOST aponta a box para um relay seu.

O link de pareamento não funciona

Os links valem uma vez e por 10 minutos. Rode pierd pair de novo para gerar outro.

Arquivos e editor dizem que a box precisa de um pierd mais novo

Rode o comando de instalação de novo (ou npm update -g pierd, brew upgrade pierd e depois pierd install): o pierd reinicia com a versão nova. Os agentes que estão rodando continuam rodando.

Notificações

Nada para configurar: o Pier no seu Mac avisa o seu iPhone e o seu iPad do que precisa de você pelo seu próprio iCloud, enquanto está aberto (Ajustes → Abrir o Pier quando o Mac ligar). Sem um Mac, o Pier mostra o que precisa de você enquanto está aberto; a box também pode enviar push sozinha com a sua chave APNs quando você compila o app (docs/PUSH.md).

Remover um aparelho

No app, Ajustes → deslize a box → Desparear. Na box, pierd clients lista os aparelhos pareados e pierd revoke <nome> remove um.
